# Hangar

## מעקב שיעורים יומי — ארשבסקי אדם

סורק את מערכת השעות של טכני חיפה (https://techni.shahaf.site/), עובר על כל הכיתות
ומוצא כל שיעור שבו מופיע "ארשבסקי אדם" — השבוע והשבוע הבא, כולל שינויים.

- **הדף:** https://claude.ai/artifact/DvKVN9W78H1c8nGkSxHUSG — לפי יום, שבוע מלא (עם סינון לפי כיתה ומורה שותף) ויומן.
- **הרצה אוטומטית:** כל שעה בימים א'–ה', מ-06:52 עד 16:52 (שעון ישראל).
- **מה נשמר:**
  - `data/latest.json` — הבדיקה האחרונה
  - `data/history.json` — רישום לכל יום (הגרסה האחרונה שנראתה באתר)
  - `data/changelog.json` — כל שינוי שזוהה בין בדיקות (נוסף / הוסר / עודכן / מילוי מקום / ביטול / אירוע)

### הרצה ידנית

```
python3 tracker/run.py              # סריקה, השוואה, שמירה ובניית site/index.html
python3 tracker/run.py --offline data/latest.json   # בניית הדף מחדש בלי סריקה
```

אין תלויות מעבר ל-Python 3. השם לחיפוש נמצא ב-`tracker/config.json`.
