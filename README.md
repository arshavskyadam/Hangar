# Hangar

## מעקב שיעורים יומי — ארשבסקי אדם, ירובוי רינה

סורק את מערכת השעות של טכני חיפה (https://techni.shahaf.site/), עובר על כל הכיתות
ומוצא כל שיעור שבו מופיע "ארשבסקי אדם" — השבוע והשבוע הבא, כולל שינויים.

- **הדף של אדם:** https://claude.ai/artifact/DvKVN9W78H1c8nGkSxHUSG (מחזיק גם את הקוד והנתונים של כולם)
- **הדף של רינה:** https://claude.ai/artifact/Rfp9BVeDpX439KVN6xo2oN
- **התצוגה בכל דף:** — עכשיו/הבא, לפי יום, שבוע מלא (סינון לפי כיתה ומורה שותף), מבחנים ואירועים בכיתות שלך, ויומן, ושעת סיום הלימודים של כל כיתה בשכבה ט. שיעורים שירדו מהמערכת (טיול, טקס, ביטול) מסומנים "לא מתקיים" עם הסיבה.
- **בדיקות אוטומטיות:** א'–ה', כך שהמערכת מעודכנת עד 07:00, 08:30, 10:30 ו-13:20 (שעון ישראל). ב-07:00 נשלח סיכום של היום (השיעורים, ביטולים, ושעת הסיום של כיתת החינוך). במשך היום נשלחת התראה רק על שינוי שחל באותו יום; שינויים בתאריכים אחרים מופיעים בדף בלבד.
- **מה נשמר:**
  - `data/latest.json` — הבדיקה האחרונה
  - `data/history.json` — רישום לכל יום (הגרסה האחרונה שנראתה באתר)
  - `data/changelog.json` — כל שינוי שזוהה בין בדיקות (נוסף / הוסר / עודכן / מילוי מקום / ביטול / אירוע)

### הרצה ידנית

```
python3 tracker/run.py              # סריקה, השוואה, שמירה ובניית site/index.html
python3 tracker/run.py --offline   # בניית הדפים מחדש בלי סריקה
```

אין תלויות מעבר ל-Python 3. האתר נסרק פעם אחת לכל הרצה. המורים שעוקבים אחריהם מוגדרים ב-`tracker/config.json` (שם לחיפוש, תיקיית נתונים, דף, ושכבות לשעת סיום). הנתונים של רינה נשמרים ב-`data/rina/`.
